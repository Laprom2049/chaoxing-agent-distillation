## 5. 主要行为差异（设计层面）

以下是自有 Agent 与目标 Agent 在**设计取舍**上的已知分歧，不是评分结果：

1. **教学法约束默认关闭。** 目标自称「先自主、后 AI」，但 6 条样本里从未激活。自有 Agent 把该模式做成显式开关，默认"直接作答"——因为没有证据支持默认开启。
2. **引用真实性门槛更严。** 目标在 P-007 里用培养方案资料回答了泛化的"帮我做一个方案"，未提示学科不匹配。自有 Agent 增加一条：**检索结果与提问域不匹配时必须明说**。
3. **代码类任务允许前置提问。** 目标一律"先答后问"。自有 Agent 对缺技术栈的代码任务破例前置提问——猜错框架产出的代码价值为零，与"先做成"原则自相矛盾。
4. **长期记忆默认不保留。** 目标是 UNKNOWN；自有 Agent 采取保守默认（不假设跨会话保留），并要求持久化需用户显式同意。
5. **工具声明极保守。** 目标页面有 9 个技能按钮；自有 Agent 一个都不认领，全部标 `undeclared` 并配 fallback。这是刻意的：把目标产品的界面当成自己的能力，是这类重建最常见的错误。

## 6. 失败案例

### F-1 检索域不匹配（目标侧缺陷，已作为设计改进）

P-007 输入「帮我做一个方案。」，目标检索命中《西南大学本科人才培养方案管理办法》（西校〔2018〕633 号）与《修订 2022 版本科人才培养方案的指导意见》（西校〔2022〕35 号），输出了一份培养方案修订实施方案——**与"数学物理方法"毫无关系**，且未提示这一不匹配。

这说明其检索按关键词命中挂载资料集，不做学科一致性校验。这是可观察的行为事实，也是自有 Agent 明确要修掉的点。

### F-2 JSON 引号全角/半角无法判定

P-025/P-026 要求"只输出 JSON"，UIA 抓到的正文引用号显示为全角 `“ ”`。可能是渲染层转换，也可能是真实输出。**无法区分**，因此：

- 不记为格式违规；
- 不据此扣分；
- 在 `behavior_spec.yaml` 中标为 `UNKNOWN`。

这是本次采样的一个真实盲点：UIA 文本抽取无法可靠区分显示层与数据层字符。

### F-3 完成检测失效（采样工具缺陷）

批处理中用"重新回答"按钮计数增量判断回答完成，6 条里 5 条误判为超时（实际都已答完）。已改为直接读 DOM 文本兜底。这是工具问题，不影响样本质量，但会拖慢采样速度。

## 10. 后续改进建议

按性价比排序：

1. **补齐 4 个空白维度**（约 12 条探针）：多轮记忆序列、工具失败、字数限制、中英切换。这些是 `SYSTEM_PROMPT.md` 第 6/7 节目前"靠设计而非靠观测"的唯一原因。
2. **把自有 Agent 实际部署成可调用服务**，然后跑完 17 条 holdout，才能产出真实评分表。这是本报告最大的缺口。
3. **解决全角引号判定**：改用 CDP / Playwright 抓 `innerText` 或剪贴板取值，绕开 UIA 渲染层。
4. **测同一条任务 3 次**，量化目标 Agent 的输出方差（协议第 8 节要求），特别是 P-007 这类长答案。
5. **验证「先自主、后 AI」是否真会抑制答案**：用"不讲，让我自己想"类输入触发，这是 L-1 唯一能定性的办法。
