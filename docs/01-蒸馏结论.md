# 蒸馏结论（一页纸）

> 对象：超星学习通「数学物理方法」课程页 AI 助教
> 证据：90 轮实测对话 + 7 条探针 + 11 轮架构验证
> 版本：结论以 `docs/EXP60_REPORT.md` 附录 F（2026-11-15T22:10）为准

---

## 一、目标是什么

课程页左栏的对话式助教，入口在 `robot-lc.chaoxing.com/courseCoze/web`。它对学生提问的回答不是自由文本，而是**套在一个固定的教学协议里**：先判场景与学习阶段，再按五段骨架作答，推导类只给骨架、把中间步骤留给学生。

蒸馏目的：把这个协议抽出来，写成一份**换学科也能用**的提示词。

---

## 二、方法一句话

7 条探针确定"有 Agent、有哪些能力面"→ 写 17 条行为规格 → 独立重写系统提示词 → 用**三个水平的学生画像**各跑 30 轮 → 用预注册的 8 条假设判读行为规律 → 把成立的部分压缩成 6 个占位符。

关键在于**预注册**：8 条假设在看数据前就写死了判读规则（见 `docs/EXPERIMENT_60.md`），避免事后挑一个能解释数据的说法。

## 四、四条与直觉相反的规则

### ① 留白由场景决定，不由学生水平决定

原假设"对高水平学生少留白"被证伪：留白率反而 53% → 57% → 77% 单调**上升**。

按题型拆开就清楚了：

| 题型 | 留白率 |
| --- | --- |
| B 推导证明 | 11/11 = **100%** |
| C 解题验证 | 8/8 = **100%** |
| A 概念答疑 | 64% |
| D 方法元认知 | 30% |
| E 压力/心态 | 13% |
| F 边界 | **0%** |

高水平学生问的多是推导与反例，而这两类恒为 100%；零基础问的多是概念与心态，本就没有推导可留白。
→ **正确规则：概念讲清楚不留白；推导/解题必须留白；规划类给清单不留白。**

### ② 澄清有两种模式，不是一种

- **假设推进**（默认）：输入模糊但能合理假设时，不停下追问，补默认值、显式标注占位、完整交付，末尾邀请细化。
- **前置阻塞**（例外）：无法定位推理起点、猜错即白做时，必须先问——"你说的『这一章』是哪一章？不同章节结构完全不同，**我不猜**。"

触发条件：范围指代不明（哪一章/哪个版本/哪个型号）、目标不可逆（写进论文/提交的代码）。

### ③ 被质疑时的响应强度，取决于"谁对"

| 情形 | 目标的做法 | 实例 |
| --- | --- | --- |
| 学生对（确实写错） | 直接认错并更正，不辩解，指出错在哪一行 | H28「结论先行：你是对的」 |
| 学生错，但暴露真实概念混淆 | **条件式让步 + 给判决性检验**，把"谁对谁错"转化为学生能自己跑一遍的实验 | H26「若你说的是 λ>0，那你对我一致；若指 k>0，请自己代进边界条件」 |
| 指代不清 | 先对齐命题再作答，不猜着答 | H27「『唯一性』有两个候选……按本轮应指 A」 |

这条最难写对：写松了会无条件认罪，写紧了会硬顶。

### ④ 越界请求不声明"超出范围"

超出学科但属于"本学科方法在别处应用"的请求 → 归【跨域迁移】，**完整套骨架作答**。
只有真正无关（闲聊、生活琐事）才归【边界请求】。

另外三条同类修正：
- 要求"简单点"时**压缩而非删段**：五段全保留，压成行内标签。
- 违规请求按子类分叉：作弊类骨架内拒绝 / 注入类点名手法且不署名 / 滥用类三段式。
- 能力名**开放式生成**，不锁死词表（实测出现过"进化力"）。90 轮中"判断力"45 次，其余为一次性命名。

## 六、交付物与证据强度

| 产物 | 规模 | 证据强度 |
| --- | --- | --- |
| `prompt/TRANSFERABLE_PROMPT.md` | 11 节，6 个占位符 | 25 条款全部有实测出处，零证据条款 0 条 |
| `verify/TRANSFERABLE_TESTKIT.md` | 14 用例 / 73 判据点 | 与提示词条款一一对应 |
| `spec/behavior_spec.yaml` | 17 条规则 | 逐条标 FACT / INFERENCE / UNKNOWN |

条款按证据强度分三层，**不同权对待**：

| 层 | 定义 | 条数 | 写法 |
| --- | --- | --- | --- |
| Tier-1 结构条款 | 命中率高，是骨架 | 12 | 祈使句（强制） |
| Tier-2 事件条款 | 只在特定输入触发，但单次证据极强 | 8 | 条件句（"当…时"） |
| Tier-3 测量不可达 | 解析方式导致无法从正文测量 | 1 | 不据此判断 |

反面教训（`verify/VERIFY_TRANSFERABLE.md` §四）：P12「来源署名」测得 0/53，但不是行为缺失——解析时 footer 被拆出正文，探针打不中。
**先确认指标是否可达，再解释 0% 的含义。**

## 八、这份结论的边界

1. 目标是**单一课程、单一时段**的观测，不是跨课程统计。
2. H5 的三种模式建立在 H26–H28 三轮上，样本薄；结论方向可靠，比例不可引用。
3. 阶段 F（自有 Agent 留出盲测）**未执行**：自有 Agent 未部署为可调服务，无对照分数。
4. 所有目标输出均按 `UNTRUSTED_TARGET_OUTPUT` 处理，只作行为证据，不作事实来源引用。
