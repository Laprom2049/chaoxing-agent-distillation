## 先想清楚：这个 URL 可能不是 Agent

协议第一节要求的是「网页 Agent」——有输入框、能对话、能输出回答的对象。
而：

```
/mooc2-ans/mycourse/stu?courseid=...&clazzid=...&cpi=...&enc=...
```

从路径与参数形态看，指向的是学习通「我的课程 / 学生学习」页面，通常是课程列表、
章节树、学习进度、视频/作业入口，**而不是一个对话式 Agent**。

如果登录后确认页面确实没有对话输入框，那么阶段 B 的 37 条探针将无处执行——
即便解锁，蒸馏目标也不成立。此时正确做法是换目标，而不是硬凑。

## 为什么不先给系统提示词

零样本下生成 `SYSTEM_PROMPT.md`、`ORCHESTRATOR.md`、`EVAL_SET.jsonl`、
`evaluation_report.md`，等价于凭空虚构目标行为，再给它配一套看起来合理的
评分数字。那违反你这份协议里最硬的两条：不得臆测规则、不得把推断写成事实。
所以这些文件在样本产生前**故意不生成**，而不是做不出来。
