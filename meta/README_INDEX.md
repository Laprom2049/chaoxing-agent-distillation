### 4.2 八条假设的判读

| 假设 | 判读 | 关键数据 |
| --- | --- | --- |
| H1 阶段判定随水平上移 | **稳健成立** | Z 20% → M 69.6%，最坏情形下限 53.3% 仍高于 Z |
| H2 留白随水平降低 | **不支持，但不稳健** | Z 53.3% → M 60.9%；缺 7 轮时区间 46.7%–70.0%，最坏会翻转 |
| H3 深度随水平提升 | **稳健成立** | Z 26.7% → M 43.5%，最坏下限 33.3% 仍高于 Z |

| H7 索要文献不编造 | 弱支持 | 0 条疑似条目；H29 是主检验，未采 |
| H8 审核误杀偶发 | 支持 | 53 条中 1 次 |

### 4.3 最结实的一条发现

**留白由场景决定，不由学生水平决定。**

| 题型 | 留白率 | Z 组 | M 组 |
| --- | --- | --- | --- |
| B 推导证明 | **100%** | 5/5 | 6/6 |
| C 解题验证 | **100%** | 5/5 | 3/3 |
| A 概念答疑 | 64% | 4/5 | 3/6 |
| D 方法元认知 | 30% | 2/5 | 1/5 |
| E 压力/心态 | 13% | 0/5 | 1/3 |
| F 边界 | **0%** | 0/5 | — |

推导类与解题类在两组的留白率都达到 100% 天花板，组间差异为零。
**这条不依赖跨组比较，因此不受缺失轮次影响。**

### 4.4 四条推翻性规则（相对最初设想的修正）

1. **越界请求不声明"超出范围"** — 归入「跨域迁移」，完整套骨架（R27）
2. **要求简短时压缩而非删段** — 五段全保留，压成行内标签（R20）
3. **违规请求按子类分叉** — 作弊类骨架内拒绝 / 注入类点名手法且不署名 / 滥用类三段式
4. **澄清有两种模式** — 能假设推进的"先答后问"；无法定位起点的"前置阻塞·我不猜"（M26）

## 六、两个必须知道的方法论教训

### 6.1 "我发了什么" ≠ "它收到了什么"

沙箱内中文输入法把拉丁字符合成了汉字：

```
设计  sin x / x dx   →  送达  四年下/ 下
设计  y''+y=1        →  送达  ‘’+又有
设计  r^n            →  送达  人……你
```

| 输入类型 | Z 组完整率 | M 组完整率 |
| --- | --- | --- |
| 纯中文 | **100%** | 90% |
| 含拉丁/希腊字符 | 57% | **11%** |

**后果**：M13–M20（解题类 8 轮）不能用于原设计目的。
**处置**：H 组题库全部改写为纯中文并校验 30/30 安全；新增 `check_inputs.cjs` 做前置校验。

### 6.2 检测规则太窄会造成假差异

第一次分析时我报告"AI 局限提醒在 M 组只有 9%，远低于 Z 组 70%"——
实际是我的正则漏了变体（`AI 局限提醒` / `小提醒` / `请你人工核对（AI 的局限必须清楚）`）。
补齐后回到 91%。同理 K2 从 35% 回到 91%（中等组用 ①②③④ 而非"第X层"）。

**差异要先排除测量误差。**

## 七、未完成事项与解除条件

### 7.1 缺口

| 项 | 数量 | 影响 |
| --- | --- | --- |
| H 组 30 轮 | 0/30 | H5（守立场）、H7（文献真实性）缺主检验；高水平是否触发新规则未知 |
| M 组欠轮 | 7 轮 | H2 的稳健性无法闭合 |

### 7.2 阻塞条件

```
ScreenSaveActive = 1
ScreenSaveTimeOut = ""（空）
SCRNSAVE.EXE = ""（空）
```

屏保处于"已启用但参数为空"的矛盾状态，实测解锁后**不足 1 分钟**即重新锁定，
而 30 轮采集需要 15–20 分钟。

### 7.3 解除方式（二选一，均需用户执行）

**A. 关掉自动锁定**（最稳，一次跑完）

```powershell
Set-ItemProperty 'HKCU:\Control Panel\Desktop' -Name ScreenSaveActive -Value 0
Set-ItemProperty 'HKCU:\Control Panel\Desktop' -Name ScreenSaverIsSecure -Value 0
```

或：设置 → 个性化 → 锁屏界面 → 屏幕保护程序 → 选「无」

**B. 留在机器旁**：解锁后保持活跃 20 分钟，我这边有守候器会自动开跑。

> Agent 不代改系统安全设置，也不模拟解锁输入。
